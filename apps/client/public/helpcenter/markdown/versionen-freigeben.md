# Entwürfe, Versionen und Freigaben

Verstehe den Weg von einer Änderung zur veröffentlichten Version.

<!-- section: welche-inhalte-werden-versioniert -->
## Welche Inhalte werden versioniert?
Designs, Playlists und Sendepläne verwenden einen gemeinsamen Freigabeprozess. Jedes Objekt hat dabei seine eigenen Versionen.

<!-- section: die-zustande-verstehen -->
## Die Zustände verstehen
| Zustand | Bedeutung |
| --- | --- |
| Entwurf | Eine Version wird bearbeitet. |
| Zur Prüfung | Eine Version wartet auf die Freigabe. |
| Freigegeben | Eine Version wurde genehmigt. |
| Abgelehnt | Eine geprüfte Version wurde nicht genehmigt. |
| Zurückgezogen | Eine eingereichte Freigabeanfrage wurde zurückgenommen. |
| Ersetzt | Eine neuere Einreichung hat eine ältere Anfrage ersetzt; dieser Zustand wird bei Playlists und Sendeplänen verwendet. |

<!-- section: eine-anderung-prufen -->
## Eine Änderung prüfen
Kontrolliere den Inhalt und die betroffenen Varianten. Prüfe bei Playlists auch Reihenfolge und Wiedergabeeinstellungen, bei Sendeplänen Zeitfenster und Zuordnung.

<!-- section: automatische-freigabe -->
## Automatische Freigabe
Ein Arbeitsbereich kann automatische Freigaben je Inhaltstyp aktivieren. Der tatsächlich erforderliche Ablauf hängt daher von den Einstellungen deines Arbeitsbereichs ab.

<!-- section: entwurf-und-live-version-unterscheiden -->
## Entwurf und Live-Version unterscheiden
Bei Sendeplänen wird die veröffentlichte Version separat vom bearbeitbaren Entwurf gehalten. Eine Änderung am Entwurf ersetzt die Live-Version nicht allein durch das Speichern.

> Wenn eine Änderung fehlt, prüfe nicht nur das Design: Auch die verwendete Playlist und der zugewiesene Sendeplan können eine andere freigegebene beziehungsweise veröffentlichte Version verwenden.
