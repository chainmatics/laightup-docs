# Exklusivprogramme und Prioritäten

Übernimm das laufende Grundprogramm für ein bestimmtes Zeitfenster.

<!-- section: eine-ubernahme-planen -->
## Eine Übernahme planen
Ein Exklusivprogramm ersetzt das Dauerprogramm während seines aktiven Zeitfensters. Nutze es beispielsweise für ein Event oder eine zeitlich begrenzte Aktion.

<!-- section: prioritaten-bei-uberschneidungen -->
## Prioritäten bei Überschneidungen
Sind zwei Exklusivprogramme gleichzeitig aktiv, gewinnt die höhere Priorität im gemeinsamen Zeitbereich. Bei gleicher Priorität wird vorläufig der früher gelistete Plan verwendet und ein Konflikt zur Prüfung angezeigt.

<!-- section: konflikte-auflosen -->
## Konflikte auflösen
Prüfe die markierte Überschneidung. Passe Zeitfenster oder Priorität an, wenn das Ergebnis nicht beabsichtigt ist. Eine Bestätigung mit „So lassen“ betrifft nur die gewählte Überschneidung.

<!-- section: weiche-oder-sofortige-ubergabe -->
## Weiche oder sofortige Übergabe
Bei einer weichen Übergabe wird das laufende Element zu Ende gespielt. Bei einer sofortigen beziehungsweise harten Übergabe wird direkt gewechselt. Die Übergabeart gilt für die Version des Sendeplans, nicht nur für einen einzelnen Plan.

> „Exklusiv“ verdrängt das Dauerprogramm. Aktive Mix-Ins werden weiterhin eingestreut.
