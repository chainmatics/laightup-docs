# Wiedergabeparameter auf einen Blick

Finde die richtige Einstellung für das gewünschte Verhalten.

<!-- section: welche-einstellung-lost-welche-aufgabe -->
## Welche Einstellung löst welche Aufgabe?
| Du möchtest … | Einstellung | Wo du weiterliest |
| --- | --- | --- |
| Mehrere Grundprogramme mischen | Gewicht | Dauerprogramme |
| Eine Aktion zeitweise übernehmen lassen | Exklusiv + Zeitfenster | Exklusivprogramme |
| Bei Übernahmen einen Gewinner bestimmen | Priorität | Exklusivprogramme |
| Regelmäßig Hinweise einspielen | Intervall und Blockgröße | Mix-Ins |
| Einen Wechsel sofort oder nach Elementende ausführen | Übergabeart | Exklusivprogramme |
| Das Display korrekt ausrichten | Rotation 0°, 90°, 180°, 270° | Geräteverwaltung |

<!-- section: haufige-verwechslungen-vermeiden -->
## Häufige Verwechslungen vermeiden
Gewicht ist ein relatives Mischverhältnis, Priorität bestimmt den Gewinner zwischen Exklusivprogrammen und ein Intervall regelt das Einstreuen. Keine dieser Einstellungen ersetzt die anderen.

<!-- section: eine-anderung-uberprufen -->
## Eine Änderung überprüfen
Setze in der Sendeplanvorschau einen Pin auf einen betroffenen Zeitpunkt. Vergleiche die berechnete Komposition mit deinem Ziel. Kontrolliere Geräteparameter zusätzlich am tatsächlichen Display.
